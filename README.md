# Rituals — рекламный дашборд

Живой отчёт по рекламе Meta (Facebook / Instagram) для пилатес-студии Rituals (Тбилиси). Главная метрика — начатые переписки в Direct/Messenger и цена за переписку (воронка построена на диалогах, не на формах/лидах). Данные обновляются автоматически каждые 6 часов и публикуются на GitHub Pages.

## Что внутри

- **Общие метрики**: расход, охват, показы, клики, CTR, клики по ссылке, CPM, начатые переписки, цена за переписку
- **Динамика по дням** — расход/переписки, цена за переписку, CTR
- **Кампании** — раскрывающееся дерево: кампания → аудитория → работающие в ней креативы
- **Демография** (возраст/пол), **страны**, **устройства** — с сортировкой "по количеству"/"по цене" и "показать ещё"
- **Все креативы** — компактные карточки, клик открывает детальную карточку
- **Стратегия** (отдельный раздел) — гео/язык/возраст таргетинга, пул интересов, сценарии видео-креативов на английском

Языковой фильтр (Все / RU / EN / KA) — работает как в остальных наших дашбордах: язык определяется по отдельному сегменту в названии кампании.

## Файлы

```
├── fetch_report.py            # тянет Meta Ads → data/report.json
├── index.html                 # сам дашборд
└── .github/workflows/update.yml   # автозапуск раз в 6 часов
```

CRM не подключена — воронка целиком строится на данных Meta (переписки как конверсия), без внешнего источника лидов.

## Как запустить у себя

Коротко:

1. System User в Meta Business Manager с токеном `ads_read`, ID рекламного кабинета
2. GitHub Secrets: `FACEBOOK_ACCESS_TOKEN`, `FACEBOOK_ACT_ID`
3. Settings → Pages → Deploy from a branch → `main` / `root`
4. **Обязательно** первым делом сверить `MESSAGING_ACTION_TYPES` в начале `fetch_report.py` с реальными данными аккаунта — раскомментировать диагностический блок в конце файла, запустить, сравнить с Ads Manager, вписать правильный тип, закомментировать обратно

Названия кампаний должны содержать язык отдельным сегментом через `_`: `RU`, `EN`/`ENG`, `KA`/`GEO` — например `001_EN_Reformer_AQ_Reels_10.08.2026`. Без этого кампания попадёт только в "Все", не в конкретный языковой фильтр.

## Настройки плана

В начале `fetch_report.py`:

```python
PLAN_MONTHLY_BUDGET = 300   # $ в месяц
```

## Известное ограничение

Подписчики Instagram (Instagram Follows) — метрика видна в интерфейсе Ads Manager, но Meta пока не отдаёт её через Marketing/Insights API (метрика запущена в июле 2025, в API её физически нет на момент сборки этого дашборда). Карточка на дашборде честно показывает "—" с пояснением вместо нуля.
